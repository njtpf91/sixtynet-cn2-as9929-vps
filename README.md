## 电信用户最该确认的：回程走 CN2 还是 AS9929

先把三条线路的分工说清楚。CN2 GIA 是中国电信的精品承载网，回程走 59.43 段节点，优先级高于普通 163 骨干，晚高峰丢包明显少，国内到美西的延迟通常在 150ms 上下。AS9929 是联通的精品线，联通宽带用户体验最好；电信用户走 AS9929 要看具体路由，去程或回程绕路了，效果可能还不如直连。AS4837 是联通常规国际线路，带宽给得大方，晚高峰表现一般。

SixtyNet 官网写线路的地方不多。明确标注 **AS9929 Optimize for China** 的只有三处：IRVINE-PRO-MICRO、那款未标价的 2 核住宅套餐，以及页面上一段没有独立标题的 AS9929 住宅配置。LAX 系列四款只写了 Premium Network 和 DDOS Protection，没有说明回国走哪条线。

CN2 的信息来自第三方测评。2025 年 10 月一篇针对 Cox Communications 双 ISP 住宅款的测评记录：电信去程 CN2 直连洛杉矶，电信回程走 CN2 链路；联通回程走 AS10099 + AS9929；移动回程强制走 CN2。2024 年 8 月另一篇针对 AT&T Mobility 住宅款的测评，三网回程都走 CN2 的 59.43 段。

这两份记录覆盖的都是住宅 IP 产品线，不能据此推断 LAX 系列也走 CN2。电信用户如果就是冲着 CN2 来的，下单前用工单问清楚具体套餐的去程和回程路由，比看宣传页靠谱。

## 住宅 IP 的两个代价：端口和退款

官网在四款 Residential 套餐下方都写了同一句提示，意思是因 IP 风控原因，住宅 IP 产品不开放 80 和 443 端口。这条限制直接决定了用途：建站、跑 HTTPS 服务、部署任何需要域名解析到 443 的应用，这类套餐都做不了。它能干的是代理中转、流媒体解锁、账号运营、内网穿透这些不依赖标准 Web 端口的事。

LAX 系列页面没有这条提示，但也没有承诺端口全开，下单前同样要确认。

## 同样的钱，选 NVMe 还是大硬盘

LAX-MICRO 和 LAX-Storage-500G 都是年付 $400，配置撞在一起：同样 4 核 4G、10G 端口、10TB 月流量，官网标称的 IOPS 都是 12500。差别只在存储：一个是 80G NVMe，一个是 300G RAID10 再加 200G 赠送，合计 500G。

多花同样的钱拿 6 倍容量，代价是 RAID10 阵列和 NVMe 在随机小文件读写上的实际差距。官网没有给这两款的实测数据，标称 IOPS 又一样，光看参数分不出来。按用途判断更实际：存备份、图床、日志归档、对象存储中转，选 LAX-Storage-500G；跑数据库、编译、容器镜像，选 LAX-MICRO 的 NVMe 更稳。

还有一组对比容易看漏。LAX-LARGE 是 8 核 / 16G，年付 $1,600；Residential-LARGE 是 16 核 / 16G，年付 $1,660。多 8 个核只贵 $60，但换成了住宅 IP 和 80/443 关闭。要算力不要住宅 IP 的，这 $60 花得不值。

## 哪些人不用考虑 SixtyNet

**明确要 CN2 GIA 书面保障的**。官网没有 CN2 GIA 的产品标注，只有第三方测评的路由记录。需要商家白纸黑字承诺 CN2 GIA 的，这家不满足。

**要建站的**。住宅 IP 系列开不了 80 和 443，LAX 系列虽然带 DDOS 防护，但端口政策没有明确承诺，建站用途要提前问清楚。

**预算卡在 $100/年以内的**。最低门槛是 LAX-STARTER 的 $200/年，折合每月 $16.7，比市面上一些低价年付方案贵。

**依赖 IPv6 的**。两份第三方测评的记录相反：2024 年 8 月的 AT&T 住宅款测评说支持 IPv6，2025 年 10 月的 Cox 住宅款测评说不支持。不同产品线、不同批次情况不一致，业务依赖 IPv6 的必须下单前确认。

**需要中文界面或国内常用支付方式的**。官网是英文页面，价格以美元计价，支付渠道页面上没有完整列出，下单前自己确认。

## 下单前要问清的五件事

1. 这个具体套餐的电信去程和回程走哪条线，能不能给 AS 号或路由截图
2. 80 和 443 端口是否开放
3. 退款是原路返回还是只退网站余额，期限多少天
4. 续费价格是多少，年付折扣是不是只限首年
5. 支付方式是否支持你手上的渠道
